# Bed Bath & Beyond

> Bed Bath & Beyond is an online home-goods retailer (bedding, bath, kitchen, decor, furniture) operated by Beyond Inc., formerly Overstock.com, which acquired the brand out of the 2023 bankruptcy. It is not an API company: its only external programmatic surface is a third-party marketplace seller API that runs as a tenant of the Mirakl Marketplace Platform, reachable only after a partner application is approved.

## APIs

- [Marketplace Seller API](https://www.bedbathandbeyond.com/partner): Base URL https://bedbathandbeyondus-prod.mirakl.net/api. Mirakl tenant; sellers generate a Shop API key from the seller portal (Profile > API Key) and send it in the Authorization header. GET /api/version answers publicly (platform 3.1306); everything else returns 401 without a key.
- [Seller API reference (Mirakl vendor documentation)](https://developer.mirakl.com/content/product/mmp/rest/seller/openapi3): The contract is Mirakl's "Mirakl Marketplace APIs" specification with a templated server (https://your-instance.mirakl.net); it is not published by Bed Bath & Beyond.
